# Mockup 섹션 — 이미지 → MP4 비디오 전환

## 배경

현재 Mockup 섹션은 5개의 정적 webp 스크린샷으로 제품 기능을 소개한다. 정적 이미지는 실제 사용 흐름을 보여주기 어렵다. MP4 비디오로 교체하면 각 기능의 동작을 직관적으로 전달할 수 있다.

## 목표

- 5개 탭(inspect, record, log, ai, submit)의 스크린샷을 각각 MP4 비디오로 교체한다.
- 탭 선택 시 해당 비디오가 음소거 자동 재생 + 루프된다.
- 기존 이미지 클릭 → 다음 슬라이드 전환 동작을 제거한다.

## 비목표 (Non-goals)

- 비디오 사운드 재생 (muted 고정)
- 재생 컨트롤 UI (progress bar, play/pause 버튼 등)
- 모바일 전용 비디오 분기 (PC/Mobile 같은 비디오 사용)
- poster 이미지 표시 (기존 webp를 poster로 유지하지 않음)
- 비디오 파일 제작 (별도 준비 예정)

## 사용자 시나리오

### 기본 플로우
1. 사용자가 페이지를 스크롤하여 Mockup 섹션에 도달
2. 첫 번째 탭(요소 검사)의 비디오가 음소거 자동 재생, 루프
3. 하단 탭 버튼으로 다른 기능 탭을 선택
4. 이전 비디오가 페이드아웃, 선택한 비디오가 처음부터 자동 재생

### 엣지 케이스
- 비디오 로딩 지연: 비디오가 아직 로드되지 않았을 때 빈 영역이 보일 수 있음 → 배경색으로 대응
- iOS Safari: `playsInline` 없으면 전체 화면으로 전환됨 → 반드시 `playsInline` 속성 필요
- 탭 비활성화 시: 브라우저가 background tab의 비디오 재생을 일시정지할 수 있음 → 허용 (의도된 동작)

## 성공 기준

- [ ] 5개 탭 모두 MP4 비디오가 음소거 자동 재생 + 루프됨
- [ ] 탭 전환 시 opacity 페이드 전환이 자연스러움
- [ ] 탭 전환 시 새 비디오가 처음부터 재생됨
- [ ] 비디오 영역 클릭 시 아무 동작 없음
- [ ] iOS Safari에서 inline 재생 (전체 화면 전환 없음)
- [ ] 기존 mockup webp 파일이 프로젝트에서 제거됨
- [ ] Lighthouse Performance ≥ 90 유지
