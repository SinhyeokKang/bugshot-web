description: pnpm build 실행 후 결과 요약
---

`pnpm build`를 실행하고 결과를 간결하게 보고한다.

## 실행

Bash 툴로 `pnpm build` 실행. timeout은 300000ms 정도로 넉넉히.

## 보고 원칙

- 성공 시: "빌드 성공" 한 줄 + `out/` 디렉터리 산출물 요약 (파일 수, 주요 파일).
- 실패 시: 에러 메시지와 파일 경로·라인 번호를 그대로 옮기고, 원인 추정/수정 제안을 짧게.
- tsc 에러와 Next.js 빌드 에러를 구분해서 표시.

## 빌드 후 테스트 체크리스트

빌드 성공 시, 이번 세션에서 변경된 파일을 `git diff` 또는 `git log`로 확인하고, 변경 내용에 해당하는 테스트 항목을 체크리스트로 출력한다.

- 변경된 컴포넌트/로직별로 브라우저에서 직접 확인해야 할 항목을 `- [ ]` 형식으로 나열.
- UI 변경: 해당 섹션을 데스크톱+모바일로 확인할 수 있는 항목 위주.
- 변경이 없거나 문서만 바뀐 경우 체크리스트 생략.

## 주의

- 빌드 전에 불필요한 파일 수정 금지. 사용자가 "수정하고 빌드"라고 명시하지 않은 이상 이 스킬은 **빌드만** 한다.
- `output: 'export'` 설정이므로 `out/` 디렉터리에 정적 파일이 생성된다.
