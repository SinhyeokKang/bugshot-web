최근 변경이 아닌 **코드베이스 전체**를 CLAUDE.md 컨벤션에 비추어 감사한다. 축적된 기술 부채, 패턴 불일치, 컨벤션 드리프트, 데드 코드, 보안 이슈를 찾는다. **리포트 전용 스킬** — 자동 fix 안 하고, 커밋도 안 한다.

## 사용

- `/audit` — 전체 감사.
- `/audit <dimension>` — 특정 차원만 집중 감사. 차원 키워드: `ui`, `seo`, `perf`, `a11y`, `style`, `general`.

## 절차

### 1. 컨벤션 로드

CLAUDE.md를 읽어 감사 기준을 확립한다.

### 2. 영역별 감사

Explore 에이전트를 활용해 아래 차원별로 검사:

- **ui**: shadcn/ui 우선, Tailwind CSS 변수 사용, 반응형 레이아웃 일관성, 버튼 사이즈 컨벤션, 같은 역할 코드 간 패턴 불일치
- **seo**: 메타 태그 완전성, JSON-LD 정확성, 시맨틱 HTML, OG 이미지, alt 텍스트, heading 계층
- **perf**: 이미지 최적화, 불필요한 JS, CSS 애니메이션 성능, Lighthouse 점수 영향
- **a11y**: 키보드 내비게이션, ARIA, 색상 대비(WCAG AA), focus-visible, 스크린 리더
- **style**: `@/` 경로, 주석 최소화, 불필요한 추상화, export 정리
- **general**: 데드 코드, 중복 로직, 하드코딩 URL, 외부 링크 정합성, 보안

### 3. 시급도 분류 + 보고

- **🔴 심각** — SEO 치명적 오류, 접근성 심각 위반, 보안 이슈.
- **🟡 권장** — 컨벤션 위반, 성능 저하, 부분 일관성 깨짐.
- **⚪ 사소** — 스타일·정리 거리.

각 항목 형식:
```
1. 파일:줄 — 한 줄 요약. (근거)
```

보고 마지막에 통계 요약:
```
---
감사 범위: 전체 / <dimension>
검사 파일: N개
발견: 🔴 X · 🟡 Y · ⚪ Z (합계 N)
```

### 4. 종료

여기서 끝. 후속 질문·액션 없음.

## 금지 사항

- **빌드 / typecheck / test 실행 금지** — 정적 코드 읽기만.
- **자동 fix 금지**.
- **커밋 / staging 안 함**.
- **추측성 발견 남발 금지** — 근거를 댈 수 있는 것만 보고.
